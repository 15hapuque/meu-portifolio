Teste da atividade 16 web, esse projeto consiste em uma página web desenvolvida para consolidar o aprendizado prático de desenvolvimento frontend e versionamento de código. A interface foi construída utilizando boas práticas estruturais e foca na entrega de uma experiência simples e funcional para o usuário. Todo o progresso do desenvolvimento é gerenciado de forma organizada através de commits e ramificações no Git.
